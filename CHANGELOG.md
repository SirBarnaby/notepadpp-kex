# Patch notes

Each KEX build is the official Notepad++ of the same version with these features built in. With automatic updates on, a new KEX build installs itself the next time Notepad++ closes.

## November 2026

### New

- **Editing motion**: edits move into place instead of jumping. Cut text lifts and goes, deleted text wipes away, pasted text makes room and lights up, undo shows what changed, moved lines slide past each other, indented lines glide, a duplicated line slides out, folds open like drawers, sorted lines glide to their places, a ring closes onto a found match and a far jump slides the page there.
- **A switch for each motion**: all 12 have their own switch in the *KEX* > *Motion* menu. Typing ends a motion at once, and fast editing skips them.
- **Animation speeds**: one speed in percent for every animation, and a speed of its own for each one (each motion, falling letters, the caret, copy flash, paint splash, tab snapping, tab slide, swipe, tab close, save glint and the quick note).
- **Touchpad tab swipe**: swipe two fingers left or right to move to the next tab. The tab follows your fingers, and you can stop half way.
- **Tab close**: a closed tab sinks below the tab bar and the tabs beside it glide into its place. New tabs rise into a gap that opens for them.
- **Save glint**: one glint of light runs across the tab and along the top edge of the editor when a file is saved.
- **Quick note pin**: the pin at the note's top right keeps it where you put it. Click it again to send the note back to the middle of the screen.
- **Quick note**: <kbd>Enter</kbd> keeps the indentation of the line above, the note opens where you were scrolled, and it can zoom in as it opens (off by default).
- **New app icon**.

### Changed

- Built on **Notepad++ 8.9.9** (was 8.9.8.1).
- KEX has its own menu in the menu bar, between *Plugins* and *Window*, with a submenu per settings page and a switch for every feature.
- KEX's settings moved out of Notepad++'s *Preferences* into a *KEX Settings* window of their own (*KEX* > *Settings...*). It shows whether each feature is running.
- Glass: the text is drawn on a layer of its own, so letters have clean edges. While you drag the window, *Acrylic* shows plain *Blur* so it keeps up on Windows 10.
- One press of <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>M</kbd> hides the quick note, also after you clicked away from it.
- Hiding the quick note no longer switches you to another virtual desktop.

## October 2026

### New

- **Copy flash**: copied text lights up for a moment.
- **Tab slide**: switching tabs slides the next document in, like switching desktops in Windows 10.
- **Paint splash**: giving a word a colour splashes paint off it.
- **Bold and italic for one token**: *Style one token* has bold and italic too.
- **Quick note file**: the quick note can keep its text in a file you choose.
- **Caret blink**: the smooth caret can fade, blink, or stay on.
- A new window on another virtual desktop gets the same token styles as the first one.

### First release

- Four views in a 2×2 grid, tab snapping, snap-out windows, smooth caret, falling letters, JetBrains keys, live token styles, the quick note, per-desktop windows, F12 hover tabs, glass and signed automatic updates.
